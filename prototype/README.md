# Киелі · kieli.kz 新版静态原型

## 怎么打开

- 直接双击 `prototype/index.html` 即可（需要联网：照片直接读取 kieli.kz 现有的 `/uploads/thumbnail/…_big.jpg`，字体来自 Google Fonts）
- 或在仓库根目录运行本地服务器，然后打开 http://localhost:5178

```bash
python3 -m http.server 5178 --directory prototype
```

## 参考 Codex 方案后的改动（2026-09-26）

- **品牌**：网站叫 kieli.kz（公司仍是 «BASTAU LINE» ЖШС，正文里照常写公司名）。Logo `assets/img/logo.svg` 和 `favicon.svg` 是 2026-10-01 设计的毡房图形：蓝色圆角底，白色毡房（顶上的 шаңырақ 和门是金色，屋顶有 уық 撑杆，墙上有 кереге 网格），颜色取自国旗的天蓝和金色。字标 kieli.kz 用标题的衬线字体，“.kz”是天蓝色（`.brand__word--site`、`.brand__tld`，见 CSS 第 13 节）。正式站的全套文件（字标、PNG 图标、分享图）在 `../src/KieliWeb/wwwroot/kieli/img/`。“Киелі”保留为哈萨克斯坦文化板块的项目名。
- **首页先介绍他**：大标题是他的名字 + “Жаңа өмірге — сенімді қадам.”，背景是天空 + 阿斯塔纳天际线（公司就在阿斯塔纳），右边是他的照片位置。
- **按需求找服务**：6 个 Tabs（Аударма / Нотариат / Көші-қон / Білім / Бизнес / Баспана）→ 32 个具体事项（护照、驾照、出生证明……）→ 统一的详情结构：Кімге керек / Не дайындау керек / Қалай жүреді / 主按钮 + “Не керек екенін білмеймін”。数据在 `assets/js/services.js`，以后对应后台的 ServiceCategory / Service 表。可以直接链接到某项服务，例如 `services.html#s-translate-license`。
- **翻译类服务**用一张“译文样张”示意（标“ҮЛГІ”），其他服务用图标插画，不用 AI 生成的假照片。
- **驾照**写作“Қытай жүргізуші куәлігінің аудармасы (Қазақстанда пайдалану үшін)”，并说明换证由国家机关决定，避免误解为“直接换哈萨克斯坦驾照”。
- **颜色**向国旗靠拢：天蓝色做强调，太阳金色做主要按钮（“Кеңес алу”“Құжатты жіберу”“Өтінім жіберу”），大面积仍是白色，文字更少。
- **文章**：带封面、分类筛选和“Маңызды”标记；新增 `articles.html`。
- **没有采用**：飘扬的真国旗（哈萨克斯坦《广告法》等对商业使用国家象征有限制，上线前请律师确认；现在用国旗配色和阿斯塔纳天际线表达同样的感觉）；中文/俄文切换（还没有这些语言版本，不放无效链接）。

## 设计系统

- **颜色**（`assets/css/kieli.css` 的 `:root`）：雪白底 `#F4F6F5`、墨色 `#0E1C21`、国旗天蓝 `#00AFCA`（装饰）/ 加深的 `#0A7EA3`（文字、链接）、太阳金 `#F3C33A`（主要按钮），小装饰用 `#A87C22`。
- **白天 / 夜间模式**：默认白天模式（不再跟随手机系统自动变黑）。右上角 ☾/☀ 按钮切换，选择保存在浏览器里，下次打开保持不变；手机端在顶部和菜单里都有。白天模式所有板块都是浅色：服务板块是浅天青色，舞蹈板块是暖沙色。夜间模式是深青色，首页大图会变成黄昏色调、文字变白。所有颜色都是 CSS 变量：`:root` 是白天，`:root[data-theme="dark"]` 是夜间，板块颜色用 `--band-*` 变量。
- **字体**：标题 Noto Serif Display，正文 Golos Text，数据（海拔、坐标、办理时长）IBM Plex Mono。三者都逐个测试过，哈萨克字母 ә ғ қ ң ө ұ ү һ і 全部支持；Playfair Display、Manrope、Unbounded、Jost 等常用字体缺字，不能用。
- **Logo**：шаңырақ（毡房顶圈）——“家、回到故乡”的象征。
- **两个世界**：“哈萨克斯坦”部分用雪白背景和大图，“服务”部分用单独的色带（白天浅天青、夜间深青），访客一眼就知道自己在哪个部分。

## 针对客户群体做的专业决定

1. **中国境内的用户**：WhatsApp、Telegram、Google 在中国打不开，所以联系方式把 WeChat 放在第一位（ID + 二维码）。上线时字体必须放到自己服务器上（Google Fonts 在中国加载不了）。旧站的“3D”其实是 Google 街景 iframe，中国用户也打不开，建议以后换成自托管的 360° 全景。
2. **Төте жазу（阿拉伯字母哈萨克文）**：从新疆来的很多哈萨克人，特别是年长的，更习惯读 төте。右上角 `Кирилл / توتە` 按钮能把整站自动转写成 төте，并切换为从右到左的排版。төте 用你们提供的 **ALKATIP Tor** 字体，已转成 base64 放在 `assets/css/tote-font.css`（约 82 KB），手机浏览器、直接打开本地文件也能正常显示；只在切换到 төте 时才加载，西里尔用户不会多下载。ALKATIP Tor 原文件缺少 дәйекші ٴ（U+0674），嵌入的版本把这个字符映射到字体自带的高位 hamza 字形；原始 .ttf 没有改动。转写规则（含 дәйекші ٴ 规则）写在 `kieli.js` 的 Script 模块，以后可以用同样规则在 C# 里做服务器端转写（对 SEO 更好）。**上线前请懂 төте 的人校对一遍。**
3. **手机优先**：大部分访客会从微信、抖音点进来。手机端有悬浮的“Кеңес алу”按钮，表单字段少，正文字号 17px，年长用户也看得清。
4. **信任感**：公司全称和地址放在服务页和页脚，流程分 5 步，公司自己的“为什么选我们”七点，客户评价标注来源路线（如 Құлжа → Астана）。
5. **专业内容**：服务页有“两个问题找到适合你的路”推荐器，还有 қандас 身份 / «Ата жолы» 卡 / 居留证 / 国籍 的对比表。中国从 2023-11-07 起加入海牙公约，中国文件只需要 Apostille、不再需要领事认证——这是很好的宣传点。
6. 官方名称是 **«Ата жолы» картасы**（不是 «Ата жол»）。

**“Құжатты жіберу”按具体文件类型保存**

- 提交的数据里有：`service=translate:license`、`code=AUD-02`、`source=services.html`，以及附件（照片或 PDF，可多选）。确认页显示编号、事项名称、所在国和附件数量。
- **每个事项有自己的链接**：`services.html#order-translate-license` 会直接打开已选好 AUD-02 的表单，可以发到微信群或朋友圈；关闭表单后地址变回 `#s-translate-license`。
- 访客改用 WhatsApp 时，消息里会预先填好编号；表单顶部也提示“在聊天软件里写这个编号”，这样微信、WhatsApp 来的请求也能区分。

## ҚАЗТЕСТ 模拟测试（2026-09-29）

- **入口**：导航“ҚАЗТЕСТ”；首页服务区下面的“ҚАЗТЕСТ-ке дайынсыз ба?”；服务里的“Қазақ тілі”“Қандас мәртебесі”“Ықтиярхат”三个事项；新闻（置顶）；页脚。
- **题库**：`assets/js/kaztest-data.js`。2026-10-01 起换成 BASTAU LINE 自己编写的题（先是两套，同一天又加了第 3 套）（国家测试中心不允许使用他们的题目）：形式、题量、难度和题型与原来相同，文章、对话、题目全部是新的，60 题全部有答案。听力题通过 `a` 指向 `clips` 里的录音；录音的 `audio` 为空时显示“Аудиожазба әзірленуде”，这一套的听力部分不评分，交卷后可以展开看录音台词。听力音频（`assets/audio/`）是用 Piper TTS 和 ISSAI KazakhTTS2 哈萨克语声音生成的（AI 声音，CC BY 4.0，播放器下面有署名）；录音脚本见 `../docs/kaztest-audio/`。新增一套题：在 `tests` 里加一个同样结构的对象，页面会自动多出一张卡片。`ans` 为 `null` 的题不计分。
- **界面**：换成网站自己的设计，白天和夜间模式都可用。考试界面始终是西里尔文、从左到右（正式考试就是西里尔文），网站切到 төте 也一样。
- **进度**：存在访客自己的浏览器里。微信切出去再回来、页面被刷新，也能点“Жалғастыру”继续；时间到了自动交卷；每张卡片显示上次的成绩。
- **时长和及格线**（按客户确认，2026-09-29）：60 题、70 分钟（`minutes: 70`）；每个部分至少 70%（`pass: 0.7`），即听力 20 题中答对 14 题、阅读 40 题中答对 28 题。成绩页每个部分显示“Өтті / Өтпеді”，进度条上标出 70% 的位置；答案不全或还没有音频的部分显示“Бағаланбайды”，不会误判。
- **页面上的规定说明**：只写了能确认的内容，并附上来源链接。2026-02-13 起的试点项目（到 2026-12-31）：申请永久居留许可、申请或延长 қандас 身份，都要通过 ҚАЗТЕСТ 在线测试，最低 A1。入籍另有一套考试（国语、宪法、历史），қандас 免考。及格线按客户确认写成“每个部分至少 70%”。
- **题目来源**：最早的题目来自国家测试中心的模拟测试（probtest.testcenter.kz），对方不允许使用，2026-10-01 已全部替换成自编题目，原来的题目和音频链接都已删除。听力音频已按脚本用 AI 声音生成（2026-10-01）。

## Omar 的照片（2026-09-28 已放入）

- `assets/img/omar-cutout.webp`（74 KB，透明背景）：首页大图和作者页。人物直接站在首页的天空和阿斯塔纳天际线前，不加背景色块，也不加阴影；太阳光晕放在右上角，不放在头后面（避免像“光环”）。作者页直接放在页面背景上，下半身渐隐。

- 以后换照片（同样是纯黑背景、4:5 半身）：运行 `prototype/tools/cutout/cut.sh 新照片.jpg`，会重新生成这三个文件。需要 macOS 14 以上、Xcode 命令行工具和带 Pillow 的 python3。

- `ConsultationFile`：RequestId、文件名、大小、存储路径。只收 JPG / PNG / PDF，单个文件建议 ≤ 10 MB；存到 wwwroot 以外，只有员工能下载（护照等属于个人数据），按公司规定定期删除
- 表单需要“同意处理个人数据”勾选（哈萨克斯坦法律要求），原型里已经有
- ҚАЗТЕСТ：`KaztestVariant`（标题、时长、排序、是否发布）、`KaztestPassage`（所属套题、序号、段落）、`KaztestQuestion`（套题、部分 Тыңдалым/Оқылым、题号、题干、补充句、A–D 选项、答案可为空、音频、对应原文）。后台录入答案后，页面上的“Жауап кілті”会自动变化
